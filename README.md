## Tạo repository mới trên GitHub

```bash
chmod +x scripts/create-github-repo.sh
./scripts/create-github-repo.sh [tên-repo] [owner] [public|private]
```

Ví dụ:

```bash
./scripts/create-github-repo.sh repo-moi phanphan07111403-boop public
```
