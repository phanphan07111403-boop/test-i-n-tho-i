# Wild Rift 7.3 — Top 10 playstyles that benefit most, by role

Patch **7.3 (Center Stage, 2026-09-22)**. Ranked by what **this patch lifts**, not 7.2 leftovers. Day-1 inference from the [official notes](https://wildrift.leagueoflegends.com/en-us/news/game-updates/wild-rift-patch-notes-7-3/).

Every playstyle below has a **rune page** (keystone + 3 primary + 1 secondary) and a **6-slot item order**. Swap LDR / Mortal / Wit’s End / Shieldbow / Mercury’s when the lobby demands it.

**7.3 rune rules used here:** Lethal Tempo now scales with *built* attack speed. **Legend: Haste** replaces Legend: Tenacity (up to 15 AH). Ingenious Hunter is gone.

Source: [7.3 patch notes](https://wildrift.leagueoflegends.com/en-us/news/game-updates/wild-rift-patch-notes-7-3/).

## ADC

Crit ADCs are the patch winners. On-hit is second (Statikk bounces apply on-hit; Rageblade no longer bans crit). Jhin / Senna / Yasuo / Yone had crit modifiers **cut**.

### 1. Trap-headshot sniper — Caitlyn

Base AD 54→60. Headshot, Snap Trap bonus, and Ace in the Hole all scale with crit chance **and** extra crit damage. High natural AS, so buy AD/crit. Hexoptics replaces Magnetic Blaster (range on takedown + far-target amp).

- **Runes:** Fleet Footwork
  - Precision: Brutal · Cut Down · Legend: Alacrity
  - Secondary: Bone Plating
- **Spells:** Flash + Barrier (Heal into poke)
- **Items:** Doran's Blade → Berserker's Greaves → Yun Tal Wildarrows → Infinity Edge → Hexoptics C44 → Lord Dominik's Regards
- **Swap:** Stormrazor first if you need lane MS now instead of stacking Yun Tal. Last slot Immortal Shieldbow vs dive, Mortal Reminder vs healing, Bloodthirster if fed. First Strike into immobile mages.

### 2. Shove-and-siege ricochet — Sivir

Fleet of Foot **31–45 → 55–70 MS**. Boomerang Blade and Ricochet scale with crit. Permanent plates + Crystalline Overgrowth + fat cannon/super minions are her map.

- **Runes:** Phase Rush
  - Precision: Triumph · Cut Down · Legend: Alacrity
  - Secondary: Manaflow Band
- **Spells:** Flash + Barrier
- **Items:** Doran's Blade → Berserker's Greaves → Yun Tal Wildarrows → Infinity Edge → Rapid Firecannon → Lord Dominik's Regards
- **Swap:** Phantom Dancer last if you need MS/kite more than RFC range. Navori Quickblades 3rd if you spell-weave Q/W more than auto. Lethal Tempo if the game is all-ins, not shoves.

### 3. Bomb-jump all-in — Tristana

Explosive Charge active multiplies with crit chance + crit damage. Rocket Jump and Buster Shot pick up **bonus AD**. Base AD 54→60.

- **Runes:** Empowerment
  - Precision: Triumph · Coup de Grace · Legend: Alacrity
  - Secondary: Sudden Impact
- **Spells:** Flash + Barrier (Ignite if you hard win lane)
- **Items:** Doran's Blade → Berserker's Greaves → Stormrazor → Infinity Edge → Fiendhunter Bolts → The Collector
- **Swap:** Yun Tal first if you will auto a lot before the first all-in. Immortal Shieldbow vs burst. Lord Dominik's vs armor. Fiendhunter after ult is the 7.3 identity (3 guaranteed crits).

### 4. Feather-recall crit — Xayah

Bladecaller is now `(base + 50% bAD) × (1 + crit terms)`. Extra feather damage 20%→25%. Fiendhunter is built for Featherstorm windows.

- **Runes:** Lethal Tempo
  - Precision: Brutal · Coup de Grace · Legend: Alacrity
  - Secondary: Bone Plating
- **Spells:** Flash + Barrier
- **Items:** Doran's Blade → Berserker's Greaves → Yun Tal Wildarrows → Infinity Edge → Fiendhunter Bolts → Lord Dominik's Regards
- **Swap:** Navori 3rd if you need E more often than ult-burst. Shieldbow vs dive. Bloodthirster if you win and stay in.

### 5. Stealth-ambush burst — Twitch

Kit rework: **AS after leaving camouflage**, Contaminate split AD/AP, no max-stack AS steroid. Fiendhunter is named for Twitch/Zeri/Yunara ults.

- **Runes:** Dark Harvest
  - Domination: Sudden Impact · Tyrant · Eyeball Collection
  - Secondary: Coup de Grace
- **Spells:** Flash + Ignite (Barrier if they have burst)
- **Items:** Doran's Blade → Berserker's Greaves → Yun Tal Wildarrows → Fiendhunter Bolts → Infinity Edge → Lord Dominik's Regards
- **Swap:** Stormrazor first for lane poke before you have ult. Runaan's Hurricane vs clump comps (on-hit + crit bolts). First Strike if you only ever appear from fog.

### 6. Lightslinger tempo crit — Lucian

Culling bullets = `20 + 20×crit + extra-crit term`. Piercing Light **100% bonus AD**. He is a crit champion now, not Mag-Blaster forever.

- **Runes:** Empowerment
  - Precision: Brutal · Coup de Grace · Legend: Haste
  - Secondary: Sudden Impact
- **Spells:** Flash + Ignite (Barrier vs poke)
- **Items:** Doran's Blade → Ionian Boots of Lucidity → Essence Reaver → Infinity Edge → The Collector → Lord Dominik's Regards
- **Swap:** Stormrazor first if lane is auto-heavy. Berserker's if you already have haste from ER + Legend: Haste. Shieldbow vs dive. Navori if you want Q/W uptime more than execute.

### 7. On-hit true-damage duelist — Vayne

Tumble **35–65% → 50–80% AD**. Silver Bolts early %HP **2/5/8/11 → 6/7/8/9**. Statikk applies on-hit to bounce targets. Rageblade lost the “no crit” tax. Lethal Tempo’s bullet now scales with the AS she buys.

- **Runes:** Lethal Tempo
  - Precision: Brutal · Cut Down · Legend: Alacrity
  - Secondary: Bone Plating
- **Spells:** Flash + Barrier (Cleanse vs heavy CC)
- **Items:** Doran's Blade → Berserker's Greaves → Kraken Slayer → Guinsoo's Rageblade → Terminus → Blade of the Ruined King
- **Swap:** BotRK first vs HP stacks. Statikk Shiv 3rd vs clump (on-hit bounce). Wit’s End vs AP. Immortal Shieldbow vs burst. Empowerment if you never reach Lethal Tempo stacks.

### 8. Overload surge carry — Zeri

Overload duration **1.5→2.5s**, crit extension **4.5→7.5s**. Excess AS→AD **50→60%**. Fiendhunter is explicitly for her ult.

- **Runes:** Lethal Tempo
  - Precision: Brutal · Cut Down · Legend: Alacrity
  - Secondary: Bone Plating
- **Spells:** Flash + Barrier
- **Items:** Doran's Blade → Berserker's Greaves → Yun Tal Wildarrows → Fiendhunter Bolts → Infinity Edge → Rapid Firecannon
- **Swap:** Stormrazor first for lane. Runaan's vs 3+ melee. Lord Dominik's vs armor. Shieldbow vs dive.

### 9. Frost-crit kiter — Ashe

Frost Shot bonus hit rewritten to scale with crit chance **and** (CritDamage−2). Slow **15–25% → 20–30%**. Ranger’s Focus mana 50→30. Hexoptics is the range Mag Blaster used to be.

- **Runes:** Lethal Tempo
  - Precision: Brutal · Cut Down · Legend: Alacrity
  - Secondary: Manaflow Band
- **Spells:** Flash + Heal (Barrier vs burst)
- **Items:** Doran's Blade → Berserker's Greaves → Yun Tal Wildarrows → Infinity Edge → Hexoptics C44 → Rapid Firecannon
- **Swap:** Stormrazor first for Energized slow/MS in lane. Lord Dominik's vs armor. Runaan's vs clump. Arcane Comet if you play W-poke more than autos.

### 10. Yun Tal stack-scaler — Jinx, Yunara

Yun Tal: 50 AD + 25% AS, **0% crit until attacks stack to 25%**. Hypers who auto constantly get a cleaner IE setup than Stormrazor’s lane burst. Jinx R was tuned down; the *item* is the buff. Yunara’s ult window wants Fiendhunter.

- **Runes:** Lethal Tempo
  - Precision: Triumph · Cut Down · Legend: Alacrity
  - Secondary: Bone Plating
- **Spells:** Flash + Barrier
- **Items (Jinx):** Doran's Blade → Berserker's Greaves → Yun Tal Wildarrows → Infinity Edge → Rapid Firecannon → Lord Dominik's Regards
- **Items (Yunara):** Doran's Blade → Berserker's Greaves → Yun Tal Wildarrows → Fiendhunter Bolts → Infinity Edge → Lord Dominik's Regards
- **Swap:** Runaan's 3rd on Jinx vs clump. Stormrazor if you cannot stack Yun Tal (short games / you get zoned).

**Do not force:** Ezreal (Q nerf), Jhin (80% crit-damage modifier), Senna bot (mist crit 15%→10%, 90% crit hits), Magnetic Blaster leftovers.

## Support

Enchanter items lost HP/AH and gained **heal/shield power**. Tank supports got cheap mixed resists + team auras. Mandate and Helia are identities, not stat sticks.

### 1. Mandate CC-mage — Nami, Lulu, Morgana, Seraphine, Zyra, Brand, Thresh

Mandate rebuilt: **60 AP**, **20 AH on CC abilities**, mark = **7% damage amp** for 4s.

- **Runes (enchanter CC — Nami, Lulu, Seraphine, Thresh):** Arcane Comet
  - Sorcery: Manaflow Band · Transcendence · Scorch
  - Secondary: Font of Life
- **Runes (mage poke — Zyra, Brand, Morgana):** Arcane Comet
  - Sorcery: Manaflow Band · Transcendence · Scorch
  - Secondary: Cheap Shot
- **Spells:** Flash + Ignite (Exhaust vs all-in ADC)
- **Items:** Spectral Sickle → Boots of Mana → Imperial Mandate → Staff of Flowing Waters or Ardent Censer → Harmonic Echo or Morellonomicon → Rabadon's Deathcap or Zhonya's Hourglass
- **Swap:** Ionian Boots if you are already hitting haste cap and need CD more than mpen. Aery on Nami/Lulu if you shield more than you land Comet. Thresh can Relic Shield into Mandate still.

### 2. Helia poke-into-heal — Karma, Nami, Sona, Seraphine, Lulu, Milio

Helia stores **30% pre-mitigation** damage, dumps it as a heal when you shield/heal an ally.

- **Runes:** Aery
  - Sorcery: Manaflow Band · Transcendence · Scorch
  - Secondary: Font of Life
- **Spells:** Flash + Ignite (Heal if your ADC is the wincon)
- **Items:** Spectral Sickle → Ionian Boots of Lucidity → Echoes of Helia → Ardent Censer or Staff of Flowing Waters → Harmonic Echo → Redemption / Salvation
- **Swap:** Boots of Mana on Karma if you are the damage. Morello 3rd vs healing. Guardian if you never poke.

### 3. Ardent hypercarry leash — Lulu, Nami, Milio, Sona, Janna, Yuumi

Ardent 2700→**2400**, HSP 5%→**8%**. Buff is a clean **30% AS + 25 on-hit magic** — rides the ADC overhaul.

- **Runes:** Aery
  - Resolve: Font of Life · Bone Plating · Revitalize
  - Secondary: Transcendence
- **Spells:** Flash + Heal (Exhaust vs dive)
- **Items:** Spectral Sickle → Ionian Boots of Lucidity → Ardent Censer → Staff of Flowing Waters → Harmonic Echo → Redemption / Salvation
- **Swap:** Mandate first if the ADC is weak early and you have real CC. Helia first if you poke. Yuumi skips boots, goes Ardent → Staff → Harmonic.

### 4. Harmonic chain-heal — Soraka, Sona, Nami, Seraphine, Milio

Harmonic Echo **links 30% heal / 35% shield** to the lowest-HP ally in range.

- **Runes:** Aery
  - Resolve: Font of Life · Bone Plating · Revitalize
  - Secondary: Legend: Haste
- **Spells:** Flash + Heal (Ignite on aggressive Sona/Nami)
- **Items:** Spectral Sickle → Ionian Boots of Lucidity → Harmonic Echo → Ardent Censer or Staff of Flowing Waters → Redemption / Salvation → Whispering Circlet
- **Swap:** Guardian on Soraka if they have three assassins. Morello vs healing. Tear start on Sona into Circlet (see #5).

### 5. Diadem mana-enchanter — Sona, Nami, Seraphine

HSP scales with **max mana**. At cap, Diadem heals the lowest-HP ally for **0.8% max mana/s**. Tear is 400g.

- **Runes:** Aery
  - Sorcery: Manaflow Band · Transcendence · Gathering Storm
  - Secondary: Revitalize
- **Spells:** Flash + Heal
- **Items:** Spectral Sickle + Tear of the Goddess → Ionian Boots of Lucidity → Whispering Circlet → Diadem of Songs (auto) → Ardent Censer or Staff of Flowing Waters → Harmonic Echo
- **Swap:** Mandate 2nd if you land CC constantly. Helia 2nd if you poke. Do not buy a second Tear item.

### 6. Abyssal aura tank — Leona, Nautilus, Alistar, Rell, Braum, Amumu

Abyssal **3000→2400**, still **12% magic-damage amp** in aura. Low-economy tanks can finish it. Pair with mage mid.

- **Runes:** Ice Overlord
  - Resolve: Courage of the Colossus · Bone Plating · Unshakeable
  - Secondary: Cheap Shot
- **Spells:** Flash + Ignite (Exhaust vs fed ADC)
- **Items:** Relic Shield → Plated Steelcaps (Mercury's vs AP/CC) → Abyssal Mask → Zeke's Convergence → Frozen Heart or Mantle of the Twelfth Hour → Amaranth's Twinguard
- **Swap:** Locket/Radiant Virtue 3rd if your backline is exploding. Thornmail vs lifesteal ADC.

### 7. Zeke delayed engage — Nautilus, Leona, Alistar, Rell, Thresh, Blitzcrank

Frostfire **waits up to 5s** if nobody is in range on ult cast. Hook-from-fog tanks finally get the item. 25 armor / 25 MR.

- **Runes:** Ice Overlord
  - Resolve: Courage of the Colossus · Bone Plating · Unshakeable
  - Secondary: Relentless Hunter
- **Spells:** Flash + Ignite
- **Items:** Relic Shield → Plated Steelcaps or Mercury's Treads → Zeke's Convergence → Abyssal Mask or Frozen Heart → Mantle of the Twelfth Hour → Amaranth's Twinguard
- **Swap:** Thresh can Spectral Sickle if you poke. Dead Man's Plate 3rd if you walk the map more than you ult.

### 8. Catcher AS-buff peel — Thresh, Rell, Leona, Nautilus, Rakan

Yordle Trap: slow/CC gives **you + nearby allies 30%/20% AS** (melee/ranged) and 20g on inspired kills. Direct ADC synergy.

- **Runes:** Ice Overlord
  - Resolve: Font of Life · Bone Plating · Unshakeable
  - Secondary: Relentless Hunter
- **Spells:** Flash + Exhaust (Ignite if you are the kill pressure)
- **Items:** Relic Shield → Ionian Boots of Lucidity → Yordle Trap → Zeke's Convergence → Frozen Heart or Abyssal Mask → Mantle of the Twelfth Hour
- **Swap:** Rakan: Aery or Guardian, Relic or Sickle, Yordle Trap → Zeke → Staff/Ardent if you shield more than you tank. Thresh Sickle start into Yordle Trap still works.

### 9. Frozen Heart walk-in peel — Braum, Leona, Nautilus, Galio, Rammus

Aura is back to “stand in them”: **all enemies in 650 lose 25% AS**.

- **Runes:** Ice Overlord
  - Resolve: Font of Life · Bone Plating · Unshakeable
  - Secondary: Cheap Shot
- **Spells:** Flash + Exhaust
- **Items:** Relic Shield → Plated Steelcaps → Frozen Heart → Abyssal Mask or Zeke's Convergence → Mantle of the Twelfth Hour → Amaranth's Twinguard
- **Swap:** Mercury's vs AP/CC. Thornmail vs Gunmetal/BT ADCs. Galio can Doran's Ring mid-support and still Frozen Heart.

### 10. Flowing Waters AP-haste — Karma, Lulu, Sona, Janna

Staff 2500→2400, HSP 5%→**8%**, HP removed. 40 AP + 15 AH on the healee — mage-comp twin of Ardent.

- **Runes:** Aery
  - Sorcery: Manaflow Band · Transcendence · Scorch
  - Secondary: Revitalize
- **Spells:** Flash + Heal (Exhaust vs dive)
- **Items:** Spectral Sickle → Ionian Boots of Lucidity → Staff of Flowing Waters → Harmonic Echo or Ardent Censer → Redemption / Salvation → Zhonya's Hourglass or Morellonomicon
- **Swap:** Mandate first if CC is your identity. Helia first if you poke. Legend: Haste secondary if Transcendence is not enough CD.

**Do not force:** Senna support (mist/crit/HP down). Old “HP + HSP + AH on one item” enchanter trees — Forbidden Idol is **HSP only**.

## Mid

Gifts: **Hwei + Sylas**, **Legend: Haste**, **Luden’s single-target bias**, **Nashor as real AP**, Force of Nature **% magic DR gone**.

### 1. Palette control-mage — Hwei (new)

10-spell kit (Disaster / Serenity / Torment + ult). Patch’s mid poster. Mandate is real if you play CC-first.

- **Items:** Doran's Ring → Boots of Mana → Blackfire Torch → Horizon Focus or Infinity Orb → Rabadon's Deathcap → Void Staff

Burst mage who copies the enemy ult. Conqueror AP ratio standardized to **1.667×**. Mid or jungle.

### 3. Luden’s isolated burst — Ahri, Syndra, Veigar, LeBlanc, Zoe, Orianna

Echo still hits the **primary** target for full damage; splash is what got cut.

- **Runes (control — Syndra, Veigar, Orianna, Zoe):** Arcane Comet

### 4. DoT battle mage vs tanks — Ryze, Cassiopeia, Vladimir, Swain, Taliyah, Hwei

### 5. Legend: Haste weaver — Ryze, Cassiopeia, Syndra, Orianna, Hwei, Ahri, Vladimir

Up to **15 ability haste** from combat. Tenacity is a *boot* now, not a free rune.

- **Runes:** Phase Rush

## Jungle

Smite burn = `30–225 (+10% bAD +12% AP +20% bArmor +20% bMR +3% bonus HP)` true damage, two extra ticks after you stop hitting. Searing Crown is gone. Start **Smite + Flash**; buy a real item, not a jungle-only Sunfire.

### 1. Tank burn-clear / engage — Amumu, Rammus, Sejuani, Zac, Maokai, Nunu, Rell, Skarner

Burn scales with **tank stats**. Twinguard is a tank capstone (300 HP + 30% bonus resists at 5 stacks).

- **Runes:** Ice Overlord
  - Resolve: Unshakeable · Bone Plating · Overgrowth
  - Secondary: Cheap Shot
- **Spells:** Smite + Flash
- **Items:** Bami's Cinder → Mercury's Treads or Plated Steelcaps → Sunfire Aegis → Frozen Heart or Abyssal Mask → Mantle of the Twelfth Hour → Amaranth's Twinguard
- **Swap:** Skip Sunfire if you already clear on Smite burn + HP — go Abyssal or Frozen Heart 1st full item. Thornmail vs lifesteal. Rammus can Dead Man's first. Grasp on Zac if you never land a hard immobilize for Ice Overlord.

### 2. Mage jungle AP-clear — Fiddlesticks, Lillia, Karthus, Brand, Evelynn, Taliyah, Diana, Morgana

Smite **12% AP**. Evelynn HP 600→630.

- **Runes (burst — Evelynn, Fiddle, Diana):** Dark Harvest
  - Domination: Cheap Shot · Eyeball Collection · Relentless Hunter
  - Secondary: Scorch
- **Runes (control — Brand, Morgana, Karthus, Lillia, Taliyah):** Arcane Comet
  - Sorcery: Manaflow Band · Transcendence · Scorch
  - Secondary: Cheap Shot
- **Spells:** Smite + Flash
- **Items:** Amplifying Tome / Haunting Guise → Boots of Mana → Liandry's Torment or Blackfire Torch or Luden's Echo → Rylai's Crystal Scepter → Void Staff → Zhonya's Hourglass
- **Swap:** Evelynn: Luden's → Void → Deathcap, skip Rylai. Lillia: Liandry → Cosmic → Rylai. Diana: Rocketbelt → Riftmaker or Nashor. Morello vs healing.

### 3. Tunnel-gank fighter — Rek’Sai (new)

Early ambush, knock-up, tunnel map. Sterak has **20% tenacity baked in**.

- **Runes:** Conqueror
  - Precision: Triumph · Last Stand · Legend: Alacrity
  - Secondary: Sudden Impact
- **Spells:** Smite + Flash
- **Items:** Long Sword → Plated Steelcaps or Mercury's Treads → Eclipse or Youmuu's Ghostblade → Black Cleaver → Sterak's Gage → Death's Dance
- **Swap:** Youmuu first if you are gank-pathing, Eclipse first if you duel. Titanic Hydra 2nd vs waves. Edge of Night vs mage CC. Ice Overlord if you play knock-up tank Rek’Sai.

### 4. Objective-setup tank — Jarvan, Amumu, Sejuani, Nautilus, Rek’Sai, Xin Zhao

Dragons/Baron/Herald have **real armor/MR**. Smite **600 → 1000 → 1400**. Burst steals lose.

- **Runes:** Ice Overlord
  - Resolve: Font of Life · Bone Plating · Overgrowth
