Long Sword → Berserkers → **Hexoptics C44** → **Collector** → **Infinity Edge** → **LDR** → **Bloodthirster**

### Vì sao thứ tự này

1. **Hexoptics ~8:00** — 55 AD, 25% crit, +10% dmg tầm xa. Long Sword vào recipe. Headshot/R cần crit *ngay*.
2. **Collector ~12:00** — IE 3500g chưa xong; Collector 3000g = 50% crit + 50 AD + lethality.
3. **IE ~17:00** — 230% crit dmg. Headshot + Ace in the Hole 7.3 scale crit chance *và* crit damage.
4. **LDR** — 25% crit nữa = **100%**. 35% pen.
5. **BT ô 6** — 75 AD, 0% crit. IE 7.3 bỏ excess-crit→crit dmg; đừng Collector/Galeforce 5th crit.

### Swap

- **RFC 3rd** (WRF Hex→IE→RFC→LDR→BT) nếu cần range — late squish DPS hơi cao hơn, mất 50 AD Collector
- Hex→IE thẳng nếu farm đủ 3500g trước 12
- Mortal vs heal · Shieldbow/GA ô 6 vs burst
- **Đừng Yun Tal** — stack 125 AA, Headshot đói crit

Pad MB03: trap tap gần địch, analog kite max tầm Hexoptics. D-pad `←` lính / `→` trụ.
